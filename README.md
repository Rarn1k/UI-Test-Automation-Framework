# UI Test Automation Framework for DemoQA

Автоматизированный UI-фреймворк для тестирования веб-приложений на основе **Python**, **Pytest** и **Selenium WebDriver**.

---

## 📄 Описание

Проект представляет собой собственный UI-фреймворк для автоматизированного тестирования веб-приложений, разработанный в рамках учебной работы.

В качестве тестируемого приложения используется сайт **DemoQA** (`https://demoqa.com`).

Фреймворк реализован с использованием современных архитектурных подходов и шаблонов проектирования, применяемых при разработке промышленных тестовых проектов. Основной целью является создание переиспользуемой и расширяемой инфраструктуры для написания UI-тестов.

В проекте реализованы:

- поддержка браузеров **Google Chrome** и **Mozilla Firefox**;
- шаблоны проектирования **Page Object Model**, **Singleton** и **Factory Method**;
- базовые классы для страниц и элементов;
- централизованное управление браузером;
- работа с конфигурацией через JSON-файл;
- логирование выполнения тестов;
- параметризация тестов (DDT);
- поддержка предусловий и постусловий Pytest;
- хранение тестовых и конфигурационных данных в отдельных файлах.

# 🚀 Инструкция по запуску

## 1. Клонирование репозитория

```bash
git clone <repository-url>
cd <project-folder>
```

---

## 2. Создание виртуального окружения

Рекомендуется использовать виртуальное окружение.

### Linux / macOS

```bash
python -m venv venv
source venv/bin/activate
```

### Windows

```powershell
python -m venv venv
venv\Scripts\activate
```

---

## 3. Установка зависимостей

Установите необходимые библиотеки:

```bash
pip install -r requirements.txt
```

Если файл `requirements.txt` отсутствует:

```bash
pip install pytest selenium webdriver-manager
```

---

## 4. Конфигурация

Перед запуском тестов убедитесь, что файл `config.json` содержит корректные параметры.

Пример:

```json
{
    "base_url": "https://demoqa.com/",
    "browser": "chrome",
    "timeout": 10,
    "headless": false
}
```

### Описание параметров

- **base_url** — адрес тестируемого приложения.
- **browser** — браузер для запуска тестов (`chrome` или `firefox`).
- **timeout** — максимальное время ожидания элементов (в секундах).
- **headless** — запуск браузера без графического интерфейса.

При необходимости путь к конфигурационному файлу можно изменить в классе `ConfigManager`.

---

## 5. Запуск тестов

### Запуск всех тестов

```bash
pytest tests/
```

### Запуск отдельного тестового файла

```bash
pytest tests/test_alerts.py
```

### Запуск с выводом сообщений

```bash
pytest -s tests/
```

### Подробный вывод

```bash
pytest -v tests/
```

# ⚙️ Настройка браузера

Выбор браузера осуществляется через параметр `browser` в конфигурационном файле.

Поддерживаются:

- Google Chrome;
- Mozilla Firefox.

Драйверы автоматически загружаются с помощью библиотеки `webdriver-manager`.

# 🛠 Используемые технологии

- Язык программирования: **Python 3.10+**
- Фреймворк тестирования: **Pytest**
- Инструмент автоматизации: **Selenium WebDriver**
- Управление драйверами: **webdriver-manager**
- Паттерны проектирования:
  - Page Object Model (POM)
  - Singleton
  - Factory Method
- Управление конфигурацией: **JSON + ConfigManager**
- Логирование: **logging**
- Параметризация тестов: **Pytest (DDT)**
