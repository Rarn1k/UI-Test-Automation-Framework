# Automated UI Testing for Steam Store

Автоматизированное UI-тестирование веб-сайта **Steam Store** с использованием **Python**, **Pytest** и **Selenium WebDriver**.

---

## 📄 Описание

Проект представляет собой набор автоматизированных UI-тестов для сайта **Steam Store** (`https://store.steampowered.com`).

В рамках проекта реализована проверка основных пользовательских сценариев:

- переход между страницами сайта;
- навигация по меню;
- применение фильтров каталога;
- проверка корректности количества найденных результатов;
- сравнение информации об игре на странице каталога и странице продукта.

Проект построен с использованием паттерна **Page Object Model (POM)**

# 🚀 Запуск проекта

## 1. Клонирование репозитория

```bash
git clone <repository-url>
cd <project-folder>
```

---

## 2. Создание виртуального окружения

### Linux / macOS

```bash
python -m venv venv
source venv/bin/activate
```

### Windows

```powershell
python -m venv venv
venv\Scripts\activate
```

---

## 3. Установка зависимостей

При наличии файла `requirements.txt`:

```bash
pip install -r requirements.txt
```

Если файл отсутствует:

```bash
pip install pytest selenium webdriver-manager pytest-xdist
```

---

## 4. Конфигурация

Проект использует конфигурационный файл `config.json`.

Пример содержимого:

```json
{
    "steam_url": "https://store.steampowered.com/",
    "use_incognito": false,
    "timeout": 10
}
```

### Параметры

| Параметр | Описание |
|----------|----------|
| `steam_url` | URL главной страницы Steam |
| `use_incognito` | Запуск браузера в режиме инкогнито |
| `timeout` | Максимальное время ожидания элементов (сек.) |

---

## 5. Запуск тестов

### Запуск всех тестов

```bash
pytest tests/
```

### Запуск конкретного тестового файла

```bash
pytest tests/tests_steam_home_page/test_case_one.py
```

### Запуск с выводом `print()`

```bash
pytest -s tests/
```

### Параллельный запуск

```bash
pytest -n 2 tests/
```

# ⚙️ Настройка WebDriver

По умолчанию используется **ChromeDriver**, автоматически загружаемый через библиотеку `webdriver-manager`.

Дополнительной настройки драйвера не требуется.

При необходимости можно заменить способ инициализации драйвера на использование локального ChromeDriver или добавить поддержку Firefox.

# 🧪 Реализованные тестовые сценарии

Проект содержит автоматические проверки следующих пользовательских сценариев.

## Test Case 1

Проверка страницы **About**.

Проверяется:

- переход на страницу About;
- получение количества игроков "Online";
- получение количества игроков "In Game";
- сравнение значений;
- возврат обратно в магазин.

---

## Test Case 2

Проверка страницы лидеров продаж.

Проверяется:

- переход в раздел **Лидеры продаж**;
- переход на расширенную страницу каталога;
- применение фильтров:
  - SteamOS + Linux;
  - Кооператив (LAN);
  - Экшен;
- соответствие количества результатов;
- получение информации о первой игре:
  - название;
  - дата релиза;
  - цена;
- переход на страницу игры;
- сравнение полученной информации.

# 📋 Тест-кейсы

## Test Case 1. Проверка страницы About

| Шаг | Действие | Ожидаемый результат |
|-----|----------|--------------------|
| 1 | Открыть главную страницу Steam | Главная страница успешно загружена |
| 2 | Нажать кнопку **ABOUT** | Открыта страница About |
| 3 | Получить количество игроков Online и In Game | Значение Online больше значения In Game |
| 4 | Вернуться в магазин | Открыта главная страница магазина |

---

## Test Case 2. Проверка страницы лидеров продаж

| Шаг | Действие | Ожидаемый результат |
|-----|----------|--------------------|
| 1 | Открыть главную страницу | Главная страница успешно загружена |
| 2 | Навести курсор на пункт меню **Новое и примечательное** и выбрать **Лидеры продаж** | Открыта страница лидеров продаж |
| 3 | Нажать **Просмотреть больше лидеров продаж** | Загружен полный каталог |
| 4 | Выбрать фильтр **SteamOS + Linux** | Фильтр применён |
| 5 | Выбрать фильтр **Кооператив (LAN)** | Фильтр применён |
| 6 | Выбрать фильтр **Экшен** | Фильтр применён, количество результатов совпадает с количеством отображаемых игр |
| 7 | Получить данные первой игры | Получены название, дата релиза и цена |
| 8 | Перейти на страницу игры | Данные игры совпадают с полученными ранее |
